# Fontes dos logotipos oficiais

Todos os arquivos em `oficiais/` foram baixados diretamente do domínio oficial de cada marca (página de marca, press kit ou media kit) ou de um repositório público que a própria página oficial indica. Nenhum arquivo foi obtido em sites de terceiros (Wikimedia, seeklogo, brandfetch etc.).

Tratamento aplicado aos SVGs: remoção de comentários XML e dos atributos fixos `width`/`height` do elemento raiz (o `viewBox` foi mantido). Nenhum caminho, cor ou proporção foi alterado.

## Uso no deck

O motor usa automaticamente o arquivo `oficiais/<id>.svg` (o id vem de `src/content/platforms.ts`). Os demais arquivos são variantes oficiais guardadas para uso futuro. Os SVGs são exibidos como `<img>`, isolados, para que estilos internos (por exemplo `.cls-1`) não vazem para a página.

| id | Arquivo usado | Como aparece |
|---|---|---|
| bubble | `bubble.svg` | Wordmark branco (o logo principal, por regra da marca), sem legenda |
| lovable | `lovable.svg` | Símbolo branco + nome |
| softr | `softr.svg` | Símbolo colorido (preferência da marca) + nome |
| weweb | `weweb.svg` | Wordmark branco, sem legenda |
| xano | `xano.svg` | Símbolo branco + nome |
| outsystems | `outsystems.svg` | Logo completo (anel vermelho + nome branco), sem legenda |
| mendix | `mendix.svg` | Logo completo branco, sem legenda |
| devin | `devin.svg` | Avatar oficial (símbolo branco em quadrado preto) + nome |
| cursor | `cursor.svg` | Cubo 2D claro + nome |
| n8n | `n8n.svg` | Logo completo branco, com largura de 100 px ou mais (regra da marca), sem legenda |
| retool | nenhum | O kit só traz versões escuras, então o deck usa o símbolo branco do simple-icons. Os arquivos escuros ficam guardados para ladrilho claro. |

Wordmarks não ganham legenda porque o nome já está no logo. Símbolos sempre aparecem com o nome em texto.

## Nota de uso

Uso exclusivamente editorial e educacional (material de aula da disciplina de plataformas no-code). Os logotipos pertencem às respectivas empresas. Não distorcer, não recolorir, não editar os arquivos e sempre exibir o logo acompanhado do nome da plataforma, respeitando as regras de cada marca listadas acima.
