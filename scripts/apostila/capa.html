Como usar esta apostila

Você vai construir, do zero, o sistema de inscrições do Hackathon No-Code 2026: uma pessoa preenche o formulário no Bubble, a inscrição fica salva no banco, o Make copia os dados para uma planilha do Google e envia o e-mail de confirmação. São 11 etapas em sequência, e cada uma termina com um resultado que você consegue conferir.

Dois caminhos para o mesmo resultado

Caminho com IA

Prompts prontos para o Bubble AI Agent e a Maia, do Make, no mesmo molde: onde, faça, com estes dados, regras, não faça, antes de aplicar. Depois de cada um, a lista do que conferir.

Passo a passo manual

Os mesmos resultados, clique a clique. Serve para fazer sem IA e para conferir ou corrigir o que a IA fez. Os nomes são os mesmos dos prompts.
